# remote-control-menu
Menu system used for STM32-based remote control for robotics projects.

# Project Overview

The menu is operated using a remote control and allows
runtime adjustment of controller gains, observer parameters,
and BNO055 sensor settings.

The primary goal of this repository is project documentation
rather than providing a generic reusable menu library. However, this might still be useful
as a reference to understand the concept behind creating menu structures.

# Key Features

- Hierarchical menu structure
- Runtime parameter tuning
- PID gain adjustment
- Observer tuning
- BNO055 IMU configuration
- Remote-control operation
